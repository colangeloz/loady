Loady

Your Mac's vital signs, in the menu bar.

Download for macOS

macOS 14 or later · Apple Silicon and Intel · free and open source

What it shows

CPU

Load per core and per performance tier, read straight from the kernel.

Memory

App, wired and compressed, reconciled with Activity Monitor.

Disk

Capacity and throughput, with APFS containers counted once.

GPU

Utilization and memory in use, per device.

Why you might trust it

  • Silent on the network by default. — no telemetry, no analytics, no phoning home. The one exception is checking GitHub for a new version, which is off until you switch it on.
  • Signed and notarized by Apple. — opens without a Gatekeeper warning.
  • Around half a percent of one core. — a system monitor should not be what's using your system.
  • Every number is cross-checked. — against top, vm_stat, powermetrics and Activity Monitor.
  • Open source, MIT. — read it, build it, verify the claims above yourself.
